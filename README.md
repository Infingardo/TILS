# TILs nella mammella · Atlante pratico

Guida tascabile alla stima dei linfociti infiltranti lo stroma (sTILs) nel carcinoma mammario secondo l'International Immuno-Oncology Biomarker Working Group (Salgado 2015; Dieci 2018), con esercizio alla cieca e confronto visivo sulle immagini di riferimento.

Pagina e web app: https://infingardo.github.io/TILS/ — installabile su telefono e desktop, funziona anche offline.

Strumento di consultazione e formazione, indipendente dal Working Group. Non è un dispositivo medico.
Immagini di riferimento 0–80%: International TILs Working Group (tilsinbreastcancer.org).
